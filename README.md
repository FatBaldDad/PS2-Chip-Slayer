# PS2-Chip-Slayer

**PS2-Chip-Slayer** is an **FBD / Fat Bald Dad** project focused on PlayStation 2 modchip control, isolation, and enable/disable management.

The goal of this project is to explore cleaner ways to control or disable a PS2 modchip without permanently removing it from the console. This can be useful for builds where the user may want the benefits of a modchip while still having the ability to isolate it for troubleshooting, compatibility testing, cleaner boot behavior, or future mod-management features.

PS2-Chip-Slayer is being developed as a possible future FBD kit, product, service-install option, or documented PlayStation 2 modding platform.

> [!IMPORTANT]
> PS2-Chip-Slayer is currently in private development.
>
> This public repository exists to document the project name, public goals, development status, and ownership of the FBD PS2-Chip-Slayer project.
>
> This is **not** an open-source hardware or manufacturing release at this time.
>
> Detailed PCB files, schematics, Gerber files, manufacturing files, wiring diagrams, installation methods, test data, revision history, and internal development notes are intentionally private until the project is further tested and ready for release.

---

## Project Purpose

Many PlayStation 2 modchip installs are permanent once wired into the console. That can make it harder to troubleshoot boot issues, compare stock behavior against modded behavior, or temporarily disable the chip without opening the console and physically removing wires.

PS2-Chip-Slayer is intended to explore a cleaner interface between the console and the modchip.

The long-term goal is to create a controlled way to manage modchip enable/disable behavior while keeping the install clean, serviceable, and easier to understand.

---

## What PS2-Chip-Slayer Is Trying to Do

PS2-Chip-Slayer is intended to explore:

- Modchip enable/disable control
- Modchip isolation for troubleshooting and compatibility testing
- Cleaner integration of modchip control into custom PS2 builds
- Reduced need to physically remove or rework a modchip during testing
- More serviceable modchip installations
- Future integration with larger FBD mod-management projects
- A possible future kit, installation service, or documented hardware platform

The public repository will grow as the project matures, but the working development files are kept private for now.
